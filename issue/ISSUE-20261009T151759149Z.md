# Pi-owned review fixes：無 source provenance 的歷史 summary 失效策略界線

合法 OM ledger 的 Observation 型別／validator 已要求非空 sourceEntryIds，Reflection 要求 supportingObservationIds；本輪可依 canonical eligible context edits 失效這些有來源證明的 derived records，不需也不允許整個 memory 關閉。來源不在當次 native window／已經 checkpoint 不代表 redaction。

但 native／legacy previousSummary 或既有 append segment 是自由文字，可能含已移除來源的 sentinel，沒有逐段 source mapping 能證明哪些字元依賴該來源。不能憑文字 marker 或全文猜測刪除 mandatory warnings，也不能偽造 span proof／宣稱 transitive full-history erase。策略界線：有可信 persisted generated-span proof 的 Blackhole OM/footer 可清除並重新投影；無證明的 native／legacy text 保留，即使重複，raw history 不變。若父要求連這些不具 source provenance 的歷史 summary 自動 selective erase，這項承諾 blocked pending 明確資料格式／遷移決策；本輪不自行擴大功能或停用 memory。

本議題不是停止其它六項修復：核心、display、settings、pending 與 native projections 繼續實作／驗證。交付不可宣稱所有歷史 private text 已被全面抹除。
