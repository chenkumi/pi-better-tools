# Session 載入時背景工作核對通知交付

日期：2026-10-08。主計畫：`plan/PLAN-20261008T113825363Z.md`。

## 結論與功能

本次授權範圍完成：Shell 與 Subagents 在 startup／resume／reload 載入 session 時，核對同 owner session／canonical cwd 的最小生命週期紀錄，必要時補發模型可見的 custom notice。通知不是 privileged system role，使用 display:true、triggerTurn:false，不啟動模型、不重跑命令、不續接 child、不重送 control、不接管舊 job registry。

- `pi-better-tools-background-state` versioned journal 保存 job/task/child session IDs、owner/cwd/runtime、allowlisted state、exit/error code、shutdown reason；不保存 command/prompt/output/control/query/credentials。
- queued/accepted intent 在 runner／managed allocation 前保存，配置完成再補真實 child IDs。最初寫入失敗拒絕提交並釋放容量；後續 journal I/O 不修改真實結果。
- Pi 1.0.0 空 SDK session／in-memory／--no-session 不保證 journal 落盤，背景 create/resume admission 以 BACKGROUND_JOURNAL_FAILED 拒絕；不私改 host flush、不偽造 user message。同步模式與 live control/query 不因此改變。
- finding 為 terminal_result_recorded、shutdown_cancellation_requested、outcome_unknown、start_not_confirmed，與 lastKnownState 分開；任何狀態均不確認 descendant process tree 已死亡，processTreeState 為 unknown。
- session-wide inventory 使用 getEntries，同 branch 通知去重使用 compaction-aware buildContextEntries；已離開模型 context 的 notice 不能抑制新 context-visible notice。不解析 compaction summary 推論結果，不保證 exactly-once 或 host acknowledgement。
- legacy Shell receipt 必須對應 assistant background:true tool call，支援真實舊版無前言格式。fork/clone 不採無原 owner 的 legacy evidence；不是所有舊歷史都能重建。
- 最多 100,000 entries、4 MiB 整體投影／解析預算、單筆文字 32 KiB UTF-8、128 jobs、每則 32 findings；超限／malformed 明說 incomplete／omitted。較舊 malformed 不覆蓋較新 terminal，較新 malformed 不退回舊成功。
- 英文安全前言＋compact JSON，full evidence/fingerprints 放 details；TUI neutral、bounded，可收合／展開完整 job/task/session IDs、outcome、reason、next action。

## 限制與未執行

未執行：production package/tarball rerun、全 root integration/check、browser、real-provider、跨 OS／WSL／SSH、manual TUI，以及 reviewer 的 final-source 獨立重審。既有 accepted tarball 是歷史產物，不含本功能，不能當作新版本驗收。

Host crash probe 使用確定性的 held runners，沒有外部 children；驗證 journal/notice/context/dedup，不驗證真正 process-tree crash cleanup。既有 module real-shell/child integration 通過也不建立完整 process-tree termination 或所有 provider cancellation 保證。Pi session retention/compaction 若實際移除必要原始紀錄，bounded reconciliation 不能恢復已丟棄資料；沒有 OS daemon、durable execution queue、fsync/power-loss guarantee。

本功能已在 source checkout 完成；使用者可在背景工作全部結束後自行 /reload 載入。本次未自動 reload，不要求重送或恢復任何歷史控制訊息。
