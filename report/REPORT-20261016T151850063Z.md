## 穩定契約
- `doctor --json` exit 0 表示報告已產生；缺少 optional 元件不是執行錯誤。不啟動 browser、PTY session、installer，不存取 provider/network，不建立 cache。
- JSON：`schemaVersion: 1`、`packageRoot`、`node: {version, executable}`、`platform`、`arch`。
- browser：`status: executable-present | executable-missing | dependency-unavailable`；成功解析時提供 root/version/executable/next。
- pty：`status: loadable | unavailable | dependency-unavailable`；成功解析時提供 root/version/owner/approved/next。
- Presence/loading 不等於 browser launch、OS library 或 PTY spawn 成功。
- Browser invocation：`process.execPath` + 自身 resolved playwright `cli.js`；不使用全域 Playwright、cwd dependency 或 npx。
- PTY：從自身解析 node-pty；最外層 node_modules 的 owner manifest 必須已精確核可 `allowScripts["node-pty@<installed version>"] === true`。hoisted 與 nested layout 均讀 consumer policy，不以 dependency policy 替 consumer 授權。只 rebuild dependency 絕對路徑，cwd/--prefix 指定 owner，--global=false。只移除原有 npm run allow_scripts promotion；保留 ignore_scripts 等其他設定。
- npm：先檢查絕對 npm_execpath 且 basename 為 npm-cli.js，再尋找目前 Node 實體位置旁的標準 Windows/POSIX npm CLI；不執行 PATH shim，不下載 npm。找不到明確拒絕。
