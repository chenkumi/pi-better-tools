## 交付

- TUI 編輯器上方新增兩個独立原生主題背景色塊：`Background Shell`、`Background Subagents`；不替換 footer、不覆蓋其他 widget、不啟用未選工具。
- Shell 顯示目前擁有的 Bash／PowerShell 背景工作、running／cancel requested、短 job ID 與 command 預覽。Subagents 顯示目前 owner／canonical cwd／runtime epoch 的 queued／running tasks、agent、title、短 job/task ID；running 優先，task 已終結而整體 job 未終結時標 finalizing。
- 接受、admission/live、單 task 完成、整體完成、cancel、shutdown 更新；無輪詢、ticker、log 讀取或 provider 呼叫。完成逐項移除，空清單隱藏；各區八列加 header／overflow，最多十行。
- UI 投影先限制 command／agent／title 長度，再移除顯示控制碼與限制欄寬；原生 Box 主題背景於 render 時計算。Private title metadata 不加入 receipt 或模型內容。UI／observer 錯誤不改工作、結果或通知；owner 更換、shutdown 與舊 epoch 回呼有防護。
- 僅 TUI 且 hasUI 綁定；RPC／JSON／print 即使支援對話框也不掛面板。取消要求或面板消失不代表 provider/process tree 已停止；不列前景、其他 session/runtime 或 OS 行程。
