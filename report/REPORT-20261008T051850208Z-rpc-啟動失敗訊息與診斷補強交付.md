- `not observed`不是證明guard沒執行；IPC可能延遲／失敗。

- Guard verified只是child報告，不代替startup檔／identity／trust／checkpoint驗證，亦不證明其他hooks已完成。
- UI request總數含notify/setStatus等fire-and-forget；目前提示僅建議檢查interactive initialization，不是證明某個UI或extension卡住。沒有保存UI標題、選項或文字。
