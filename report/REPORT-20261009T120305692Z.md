## 實作與安全邊界

- command 使用有效 trust-aware Shell 設定與 Pi 1.1.0 shell resolver/environment/cancellation helper；分離 stdout/stderr、非 PTY、stdin ignored、actual close barrier。Legacy stdin command transport 在 spawn 前明確拒絕，不偷偷 fallback。
- managed child 使用既有 explicit identity，無 Monitor tool registration，direct execution fail closed；不由 RPC/cwd 推定身分。
- job observation 唯讀；lease 前後驗證 owner/canonical cwd/runtime generation，revoke/load-order 支援。Subagents 使用原 `BackgroundJobs.get` 的 provisional-safe view，不輸出私人 query answer，不 cancel 被觀察 job、不呼叫 provider。
- WebSocket 預設 public wss；private network 與 insecure ws 分別逐 URL 明確 opt-in。Validated DNS 全集合固定為 actual connect lookup，TLS/SNI/cert verification 保留；拒絕 userinfo、其他 scheme、redirect、binary、oversize，關閉 compression/reconnect，preallocation payload 16KiB，handshake 受 15s/總 TTL 限制，摘要隱藏 query/fragment/path。
- bounded UTF-8/CRLF/EOF parser、stderr 8KiB tail、60 events/rolling minute、600 total、4 active/32 retained、per-monitor/owner pending caps、32 events/32KiB batches、30s progress throttle、total duration 包含 startup。
- busy latch 用 agent_start/agent_settled；wakeAgent false 不觸發模型回合。同步 send throw 保留 batch、最多三次 bounded retry；submitted/delivery_unknown 不 replay。
- actual source close 不等於 descendant process-tree cleanup；submission 不等於 host acknowledgment/persistence acknowledgment。停止 job observation 只解除 observer。Renderers 只有 `cleanupEvidence.sourceClosed===true` 才顯示 close。
