## 模擬邊界、禁止項目與剩餘驗收

唯一 synthetic 邊界為註冊的 offline provider：payload 的正常建構、provider setup barrier、assistant 回應不是 built-in OpenAI HTTP/SSE bytes。**ctx、SDK session、setModel、ModelRuntime、runner、產品 hook 與 request-local identity 都是真實 1.2.0**。目前證據確認本地錯配，未聲稱真實 backend tier 接受／拒絕、費用或服務延遲已驗證；也未重現特定 built-in auth/header await 位置。這不妨礙本候選「host 可交錯導致本地 tier 錯配」confirmed。

未讀真實 auth、未呼叫真模型／credentials／paid provider／network。ModelRuntime `allowModelNetwork:false`、`refreshOnCreate:false`、`modelsPath:null`；fetch 額外 throw。沒有 install、產品／既有 tests／依賴／globalsettings 改動；沒有 fullsuite、npm test/module/cross/typecheck/build/package，未執行不算通過。沒有 sleep／idle/poll probe；10秒 interval 只印英文進度，120秒是子程序總上限，不是斷言／判定依據。

修正後驗收：同一 1.2.0 真實 pipeline 三次 fresh-process 重跑；固定 luna request 在切 sol 後仍須符合 priority（或文件化的保守不注入策略）、sol request 不得因選取 luna 而誤降速、非 GPT request 不得注入 tier；三個無切換 controls 保持。優先 request-local provider/model，若宿主缺乏身分，採一致性檢查／fail-closed 並明列能力限制，不能只從 payload model 名稱推測 provider。保留單一 request、錯誤為空、terminal、exit 與 cleanup assertions。此次沒有實作修復；將本補驗缺陷 assertions 直接當成修正後 green 測試不符合驗收。
