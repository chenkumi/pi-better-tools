### 3. rg 解析、override 與只複製 binary
- `test-tools.mjs:12–16`：Windows 使用 win32 分隔符與 rg.exe；PATH／Path 共存時採排序後第一個 case-insensitive key。POSIX 使用 PATH、冒號分隔與 rg；quoted entries、symlink canonicalization 均有處理。
- `test-tools.mjs:14,17–27`：非空 explicit override 只產生一個 candidate；失敗不偷偷 fallback PATH。缺少工具、無法啟動、非零退出或不是 ripgrep version banner 皆形成明確 prerequisite failure，不 skip、不下載。
- version probe 使用 argv、無 shell；probe env 只保留有限 OS／PATH keys，不傳 HOME、credentials 或 provider variables。解析 override 來自父測試環境；isolatedEnv 不把該 override 帶入 runtime child，與「測試專用變數」契約相符。
- `test-tools.mjs:30–38` 僅建立 isolated home/.pi/agent/bin、以 COPYFILE_EXCL 複製已解析的單一檔案；Unix 保留執行 mode。沒有讀／複製來源 agentDir 的 auth、settings 或其他內容，沒有修改來源 binary、全域 PATH、runtime dependencies。SHA-256 是複製後內容記錄，不是供應鏈驗簽。
- 單元測試涵蓋 casing、bad override、missing prerequisite、symlink 與 exclusive copy／source preservation／Unix mode；以 injected probe 避免依賴本機 rg 或網路。
