### 修正政策

- `child-startup-receipt.ts`：process-global Symbol.for WeakMap 以**已消耗 handshake object identity** 作 invocation lease key；只有初次 exclusive open(`wx`) 寫入、成功 close、並完成只讀驗證的 valid receipt 才取得重用資格。不是按 id／payload／path 查找或接管既有檔案。
- Reload 僅以同 startupPath、regular file／非 symlink、bigint dev／ino（不可為 0n）、固定大小及完整原始 bytes 做只讀驗證；比較 lstat／fstat 身份並確保讀取期間檔案身份未變。新 object 即使 full encoded payload 完全相同，仍 exclusive 建立；不覆寫外來 receipt、不重建遺失檔案、不接管被替換／變造的 receipt。未將 wx 一律改 w。
- `child-guard.ts`：model／cwd／native session ID／thinking／trust 每次 session_start 重新驗證；配置或 trust 拒絕優先於 receipt I/O 診斷，輸出 `guard_rejected`；receipt 故障輸出 `guard_failed`。**兩者直接 process.exit(1)**，即使 stderr write 失敗亦退出，不再以 ordinary handler throw 當 provider fence。純 fault fixture 攔截 exit 後仍保留原 exception 斷言。
- 主代理 Shell 背景契約、activation／settings／backend／cancel／recursion exclusions、builder、ready-query 與 admission ownership 格式沒有改動。
