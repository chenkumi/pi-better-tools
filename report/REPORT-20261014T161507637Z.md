## Mocks、排程與驗證邊界

- 外部 mocks：public process backend、Pi extension registration／event dispatch／sendMessage、UI 宿主與色彩；真實 SessionManager journal、host shell definition／accumulator、產品 entry／factory／jobs／handoff／UI mapping/signature／Monitor projection 沒有抄寫或 mock。
- `setTimeout` 只攔截產品預設 180000ms 門檻，明確呼叫 callback；`setImmediate` 是可釋放 deferred boundary。沒有等待 180 秒、固定 sleep、idle probe 或靠 watchdog 判定 timeout。shutdown 的真實 2000ms fallback timer 未觸發，在 job.done 完成後由產品清除。
- runner 的 60000ms 是防止失敗 child 永久留存的整體 safety deadline；全部 child 自然退出 0，未命中 deadline。沒有 `process.exit(0)` 掩蓋 leaked handles。
- backend 是 mock execution，不是 OS process sandbox；確認 abort 橋接缺陷，不宣稱 descendant tree 泄漏或清空。生命周期 dispatch 是 external host seam，未跑真實 Runtime.dispose／CLI shutdown；此報告不是完整 Pi loader/runtime integration certification。
- 已跑最小自訂動態 repro：初版九次成功，增補 F1 正向對照與 F3 no-late terminal／追加 bytes 後，最終九次再次成功；保存 final source 與 final 九個 logs。執行後逐個核对九次記錄的產品 SHA-256，全部一致。
