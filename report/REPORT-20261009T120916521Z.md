**指定負向條件的控制流程核對：**

| 條件 | 修正後拒絕理由 |
|---|---|
| File call／same-ID non-File result | originating ID 使 File authority 為真；same-name result 不成立，直接拒絕 |
| duplicate File calls 或 File/bash mixed calls，任一順序 | originating ID 保留；shared pair 被移除，不落 legacy action map |
| duplicate results，含 File/non-File mixed results | shared pair 被移除；所有同 ID File authority results 都拒絕 |

| assistant-only／missing result | 沒有 acknowledged activity，File args 不再 seed legacy map |
| provider-unexecuted／cancelled host error | host error 排除，亦不能由 native call-derived seeds 復活 |
