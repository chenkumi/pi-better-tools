兩case都有合法assistant(toolUse)→toolResult pair，native split prefix精確user＋call＋result三筆，順序及toolCallId保留；最新final在retained tail，不被塞回summary input或summary正文。

### A — retained-final

user＋text-free工具call/result＋最新final。Native firstKept精確等於該最新assistant entry ID；不存在更早ordinary assistant候選，因此plain display copy **0**。Resume後該final在visible context及模型projection恰好一次，無copy／summary duplicate。再次session_compact event仍0。

### B — dropped-final

前個user/task＋較早working text＋前個完整final，再追加合法新user、text-free工具call/result與最新final。原生keepRecent8選最新final，前個final確实在native summarized input。Plain custom copy **只有1份**，source ID精確是newest dropped previous final，不是working text或retained latest final。

前個final帶ANSI controls及多行UTF8；stored copy必須精確等於全部去control文字、truncated=false。Compaction後所有rawBefore entries逐一deepEqual，resume歷史仍有原source但visible context沒有它；latest final仍retained。Persisted plain custom在resume visiblecontext可見，`sessionEntryToContextMessages`及canonical projection均為**0模型訊息**。真renderer顯示Previous output與三行完整文字（含中文），不顯示latest final；duplicate event不新增entry。
