## Critical (must fix)

### R-HTTP-01：HTTP 101 的 close 不會結束 headers 等待
- **位置：** `modules/web-tools/src/fetch/http.ts:94–98`；影響延伸至 `service.ts:234,390–394,403–413`。
- **狀態：** P1，靜態確認；未執行 socket 重現。
- **觸發：** 缺 browser 的 HTTP fallback 遇到公開站點回覆 `101 Switching Protocols`、`Connection: Upgrade`、`Upgrade: websocket`。不涉及私網或 DNS rebinding。
- **證據：** 產品 headers promise 只監聽 response／error。Node 22.22.2 upgrade 分支不 emit 普通 response；沒有 upgrade listener 時銷毀 socket，且 req.res 已設定，socket close 分支只 emit request close，不 emit request error。之後 destroy 已 destroyed request 直接返回，故產品 promise 永遠 pending。citeturn1view0turn1view1
- **影響推導：** deadline／取消無法再靠已關閉 request 的 error 喚醒等待，finally 不執行，queue permit／operationCleanup 不釋放。累積至 maxConcurrency 耗盡容量；close 等待 operationCleanup，使 shutdown／reload 也卡住。
- **最小修正：** response 尚未交付即 close 時 reject；AbortSignal 直接 settle headers 等待，不只依賴 request error。若顯式處理 upgrade，必須拒絕並銷毀移交的 socket；保留一次 settlement、listener cleanup，以及等待 request close 後釋放名額。
- **最小回歸：** 本地 raw TCP／HTTP fixture 回傳 101，以事件 barrier 驗證 fetch 拒絕、取消及 service.close 完成、operation 集合清空、queue 可重用；不新增固定 sleep timeout 測試。現有 `tests/integration/static-http.test.ts:49–95` 沒有 101 分支。
- **固定來源：** `https://raw.githubusercontent.com/nodejs/node/v22.22.2/lib/_http_client.js`，destroy／socketCloseListener／socketOnData／parserOnIncomingClient，約 462–476、490–519、588–622、645–666 行。

### R-SETUP-01：installer 改 cwd，讓相對 browser cache 與 doctor／runtime 分離
- **位置：** `setup/core.mjs:24`；對照 `61–66,88`。
- **狀態：** P2，靜態確認；未下載瀏覽器。
- **觸發：** 從非套件目錄 A 直接執行 CLI，`PLAYWRIGHT_BROWSERS_PATH=./browser-cache`，沒有 INIT_CWD。
- **證據：** doctor 保留 cwd A；installer cwd 卻改成 packageRoot B，環境不變。Playwright 1.64.1 registry 以 INIT_CWD 或 process.cwd 解析相對 cache，因此 doctor／同目錄 Pi 使用 A/browser-cache，但安裝使用 B/browser-cache。citeturn1view2
- **影響：** 同實例、同環境下安裝成功仍可能缺 browser、繼續 fallback 或 selector 失敗；唯讀 packageRoot 也可能新增不必要的權限錯誤。
- **最小修正：** browser 子程序保留呼叫者 cwd；Playwright CLI 已從本實例解析為絕對路徑，不靠 cwd 找依賴。若選擇先正規化 cache，需保留 `0` 特例，不改全域環境／設定；前者改動較小。
- **最小回歸：** 任意 cwd、相對 cache、無 INIT_CWD，比較 doctor executable 與 installer 子程序 registry directory；唯讀 registry／stub CLI probe 即可，不需安裝。現有 PTY `setup.integration.test.mjs:16–25` 與 `scripts/package-smoke.mjs:143` 都用絕對 cache。
- **固定來源：** `https://raw.githubusercontent.com/microsoft/playwright/v1.64.1/packages/playwright-core/src/server/registry/index.ts`，registryDirectory，387–405 行。
