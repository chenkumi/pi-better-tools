## 界限／剩餘風險
- bounded projection：100,000 scanned entries、4 MiB relevant serialized payload、64 KiB per entry、32 nested records、5 levels、8192 chars/string；summary 16 refs / 8000 structural chars / 約1600 chars/entry；previous-summary ref inspection prefix 128 KiB。超限 fail closed 並報 incomplete；大型 historical records 可能無正常 e: 投影，raw history 不變。
- e: paging 是 selected bounded data，不是完整 private/raw payload recovery；producer capture 的 outputTruncated=false 不表示本投影完整。原始 clipped text 仍留 JSONL，不能宣稱已全部經 recall 返回。
- Credential fields可靠排除；public prose 的 common assignments/API keys/Bearer/URL userinfo/control/bidi scrub 是 defense in depth，無法識別任意 unlabeled secret。沒有宣稱 OS sandbox 或模型一定不受惡意資料影響；僅確保程式不升權／不將它當 heuristics 指令。
- 已知 #N shorthand scope:all 缺陷不直接阻礙 e: 路徑，本包未修；drill-down byte-limit 等 B/C 一般缺陷也未改。
- 真實 producer jobs/lifecycle 的 cross-module delivery/reconciliation、付費provider、人工TUI 不在此證據範圍。此 fixture只驗證持久化後消費端，不宣稱 exactly-once delivery 或 process cleanup。
