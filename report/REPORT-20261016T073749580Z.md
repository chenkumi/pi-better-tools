## 功能

入口 `modules/file-audit/src/index.ts`。提供 `/file-audit [status|check|clear|limits --window 4 --max-files 50]`；預設 4 before_agent_start runs／50 個不同檔案，成功 read/write/edit/note 才納入，容量在新增時淘汰，同檔更新最後活動排序。Note 實際路徑取成功結構化結果，與後續 read/edit 共用名額，不保存正文。Nested calls 正常追蹤。

手動 check 才讀 cwd 下三份 provenance JSON 與獲准候選；metadata 合計 8 MiB／50000 inventory 項目，候選單檔 8 MiB／合計 32 MiB，最多一個 scan，沒有 watcher／模型工具／模型呼叫／活動資料庫／完整歷史重建。缺紀錄、超限、外部／credential 路徑、讀取途中變動不算通過，也不推論修改作者。Session/reload/tree/shutdown 撤銷舊觀察；TUI 摘要不進模型 context。

根 manifest 已更新為 17 本地模組／19 entries；同步 module runner、package files、loader probes、根文件、pi-tools-config 自給自足 reference 及 provenance，無新 dependency／lockfile 或全域設定改動。模組可獨立載入／排除，不 runtime import File Tools 或 Note Tools。
