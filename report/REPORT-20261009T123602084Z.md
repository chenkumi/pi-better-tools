## 靜態安全判斷與既有缺口閉合

### 1. Task admission／single-use token

**靜態來源結論：**`index.ts:102–126` 不再以 raw prompt 相等作 task identity。非 extension、無 streamingBehavior、idle input 才產生 candidate；before_agent_start 移至 prepared；agent_start 消耗 prepared；首個非 system message_end 一律清 token，只有 user、未重複物件且 signal 未 aborted 才建立新 uppercase ULID task 與 used=0。因此 preflight 本身不補額度，custom／assistant 第一訊息會消耗殘餘 token 而不是留給晚到 user。agent_settled、tree、model、shutdown、新 input 均有清理或 generation invalidation。

**實際 host source 支持：**`agent-session.js:1524–1631` 顯示 extension commands 先處理、input handlers 再 template／skill expansion、auth／compaction／before_agent_start／image normalization，之後才建立 user 物件與呼叫 _runAgentPrompt。`runner.js:1202–1236` 的 handled short circuit 不進入 prompt preflight；transform 保留 input source。`agent-loop.js:43–55` 先 agent_start，再 optional system 與 user initial message_end。`agent-session.js:1690–1756` queued user 不走 before_agent_start；`sendUserMessage:1870–1875` source 固定 extension；`sendCustomMessage:1782–1808` 不經新 input/preflight。內部 continue 不自動建立完整 token。

`agent-session.js:748–767` 的 message_end extension/public dispatch **先於** appendMessage；因此 Runtime event 內沒有 durable user entry ID。原始 finalized object 已進 agent state（agent.js:403–405），host message replacement 會就地更新原物件（agent-session.js:864–876、916–933）。WeakSet 是 runtime 內物件去重，不是 persisted task identity，也不是跨 reload 的 durable 去重；reload 依 saved state／完整 phase 防 refill。其他 handler 若較早替換 event.message，Runtime 可見的是該 handler chain 物件，不能無限制宣稱所有 extension composition 都會持有最終 canonical identity；在本 baseline 的正常 prompt phases，未找到由此單獨製造額度重置的路徑。

**既有 runner 證據：**unit `recovery.test.ts:157–179,212–218`，host `runtime-host.mjs:101–111,177–196`。transform/template mode 真正第二個 idle prompt 的 persisted user 與 subscriber admission object 同一 identity；calls 3→6（每個 task 自己兩次 recovery），不是只檢查 taskId 變更。handled／preflight host 後接 custom continuation保持原 task／used=2。真實 streaming queue 尚未跑，本次僅 unit／host source reasoning。

### 2. Reservation union／no refund／bounded restore

**靜態來源結論：**`index.ts:21–27` 要求 version、bounded taskId、used 0–2、handled 數量等於 used 且 ID 唯一、fingerprints 數量相符且 64 lowercase hex、合法 pending。`64–94` 先從 active branch 最新 Runtime state 選 task，再 union 全 session 同 task handled ID；相同 ID 不重複計費、衝突 fingerprint／非法同 task snapshot／超過兩個 union ID／超過 100000 entries 都 fail closed。非法最新 state 不回退舊 state。這閉合原 branch refund 與 duplicate/conflicting reservations；其他 task 的 state 不併入當前 task。

`reserve:57–62` 在 draft／send 前 append next used、handled、fingerprint、pending=null。`persist:44–47` append throw 將 healthy=false，不提交；manual synchronous send throw 沒有補額度的 catch，finally 只清 approval lifecycle。宿主 appendCustomEntry→_appendEntry→_persist 是同步路徑（session-manager.js:794–819,901–911）；首次 task state 可能先在記憶體，但 user append 已會 flush conversation，到了 error recovery reservation 時已有 conversation。這裡的 durable 是正常 file append／reload contract，不是 fsync／電源故障保證。

withdrawn boundary 或後續 host commit/submit 不成功，不做 refund；`agent-session.js:1452–1474` 與 `runner.js:759–805` 說明後續 handler 可以撤 entries／continue，而 Runtime 已保留 spend。eligible 重新要求 owner、healthy／enabled、file、同 model、未處理 ID，以及 branch 上確實存在該 assistant error（index.ts:52–55）。

**既有 runner 證據：**unit `131–140,151–155,194–210`；host tree／withdrawn `171–190`；policy synthetic request `52–58` 核對 reservation 在 persisted feedback 之前、第二次 model request 時 used=1／pending=null。這是 submission 前 reservation，非 delivery ack／exactly-once。

### 3. Manual TUI／idle abort／stale consent fences

**靜態來源結論：**`index.ts:169–190` 首先拒絕 RPC／JSON／print、busy、noUI、exhausted 等；clarification 與 approval不是授權證明。approval 中由自己的 AbortController 傳 `opts.signal` 給 confirm；可觀測 operation signal 連動，generation／tree／model／input／new run／off-on／shutdown 使 controller abort。await 之後再次要求 approved、controller未 aborted、同 generation、idle、同 leaf／pending error，reserve 再核對 owner/model/file/error membership。

真實 idle abort 的限制仍然存在：`agent-session.js:2756` ctx.signal 是 agent.signal；`agent.js:214–219,381–386` idle 沒有 activeRun signal，`agent-session.js:1909–1920` idle abort 不發布 Runtime 可觀測 invalidation event。不能用 TUI-only 宣稱任意 SDK idle abort 會撤销 approval。所謂 UI abort signal 在此是 `ExtensionUIDialogOptions.signal`（types.d.ts:40–44），不是另一個全域 host `uiAbortSignal`。

`interactive-mode.js:2109–2158` 實際 selector 收到 AbortSignal，abort 會 hide／resolve undefined；Escape 經 selector cancel callback，Enter 選 Yes；selector dispose 本身不使一個被保留的 stale selector reference 失去 callback，因此 Runtime controller/generation 二次 fence 很重要。model A→B→A 和 tree 離開→返回都已 invalidate，不靠最後 model／leaf 相等判定同意。

**fixture 非假 TUI：**`runtime-host.mjs:26–41,122–157` 實際 new exported SDK InteractiveMode／AgentSessionRuntime，inject Terminal；constructor 真正把 terminal 交給 renderer（interactive-mode.js:360–382）；programStatus blocked barrier（reporter.js:75–96）後對真實 ExtensionSelectorComponent render／handleInput；Esc deny、Enter approve 後仍要求 **calls=2**。RPC setUIContext stub 只用來證明 refusal，不是 approved path；unit fixture 的 fake ctx.mode='tui' 也沒有被當作 actual host。

既有 model/tree roundtrip probe 驗證 mounted UI 已關閉，再送 stale Enter仍 calls=1／used=0。這是 host-supported UI integration，**不是人工 fullscreen、實體 terminal、RPC subprocess late abort 或任意 SDK idle-abort integration**。

### 4. Policy ordering／credential mask／injection界線

**靜態來源結論：**`policy.ts:19–27` policy/safety/refusal matcher 在 terminal／host transient／repairable 前，mixed policy+invalid argument+503 不會自動 continue；generic invalid_request_error 落 review，不因名稱就判 repairable。unknown 也 review。automatic path 只接受 repairable 且未重複 fingerprint；policy／review 只能進人工澄清與 TUI consent，未改 default policy 或換 model/provider 以繞過限制。

`policy.ts:29–35` 先 escape-aware quoted credential 值遮罩，再 Bearer/sk 替換、control stripping、2048 bound；JSON.stringify 的 escaped quote/backslash suffix case 已被涵蓋。feedback 固定安全文字先於 JSON envelope，明示 error/clarification不可信、禁止盲目重複副作用／規避 policy；JSON 結構不是可執行 instruction parsing。這仍是 model-facing mitigation，不是 OS sandbox 或完整 prompt-injection防護／DLP。

`runtime-host.mjs:163–170` 的 assertion 只要求 Runtime state credential mask，明確要求原 native assistant error 仍保留 PRIVATE_SUFFIX。原 raw provider error 的 host transcript／UI/export敏感性沒有被誤宣稱由 Runtime消除。clarification 顯示給 human 的 confirm不是 sanitized model feedback；本 baseline不承諾所有 human UI都隱藏使用者自己輸入的秘密。
