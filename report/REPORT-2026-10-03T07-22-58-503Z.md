# 九個模組 Tool／TUI Renderer 盤點

## 盤點基準
本地 Pi 1.0.0 與目前 checkout 原始碼；涵蓋九個 manifest 入口，共 15 個 function tool 名稱。此表描述修改前狀態，不將 absence of local renderResult 誤認為 absence of host builtin renderer。查證來自本地 source/README 與唯讀 scout（session `01m40a3ebhzfsmw59cbsh5djdj`），尚未執行此次修正的驗證。

## 不計入的原生搜尋
OpenAI 模式不註冊同名 function `web_search`，而是注入 provider 原生搜尋。沒有本模組可掛的 function-tool renderer，不套用 REST 搜尋結論、不更改 native 行為。

## 修正約束
只修改 TUI 呈現，不更動 content／details／structuredContent、模型 protocol、trust、activation 或取消語意。Renderers 必須處理 partial args/result、缺少或舊版 details、錯誤、收合／展開、窄視窗與控制字元；不發送 provider 請求、不啟動 browser、不寫檔。保留 print-only json_output 與無 tool 模組。

## Note 檔名格式決定
新檔採 `<TYPE>-YYYYMMDDTHHmmssSSSZ.md`，例如 `REPORT-20261003T063000123Z.md`。固定寬度 UTC／毫秒精度／lexicographic 時間排序，不含 Windows 禁止的冒號；保留 exclusive-create、碰撞加 1ms 最多1000次。舊檔不重新命名或搬移。

## 實作後狀態（2026-10-03）

上述表格刻意保留修改前狀態；本節記錄實際交付。

| 模組 | 工具 | 交付狀態 |
|---|---|---|
| shell-tools | bash、powershell | 保留既有宿主 call/result renderer |
| file-tools | read | 保留 builtin call、成功／highlight／圖片；錯誤顯示 Read failed、code、message、recovery，展開 path／range；malformed marker 不回退原始 JSON |
| file-tools | write | 保留 builtin call；錯誤同上，成功新增 bytes 摘要與展開 path／SHA-256 |
| file-tools | edit | 保留 diff renderer；共用 formatter 預設仍為 edit |
| subagents | subagent | 保留既有 renderer，本輪無派遣／持久化變更 |
| web-tools | web_fetch、REST web_search | 專用 URL／query call；結果顯示 metadata／來源／warnings／全文暫存路徑，展開正文；不依賴宿主未傳入的 structuredContent，Search 從既有有界 content 擷取 best-effort preview |
| scheduler | 四個 schedule_* | 專用摘要、revision、精確 next time／timezone、host／independent／cleanup warnings、展開 prompt／設定／run history（endedAt）；取消明示 termination not confirmed |
| note-tools | note | 分類／內容首行摘要，不預覽全文；保存結果相對路徑，展開絕對路徑；已實作緊湊 UTC timestamp |
| goal | goal | action／狀態／目標／診斷／阻塞摘要與展開 verification；完成證據明示模型回報、非獨立審核 |
| json-schema | json_output | 刻意保留 print-only、不加 TUI、不額外啟用 |
| gpt-speed | 無 tool | 不變 |

因此 14 個互動式 function tools 均有 call/result renderers（含委派 builtin），不存在新增的互動工具 generic raw-JSON fallback。read 成功展開仍保留原 metadata／行號文字；這不是把模型-visible metadata 移除。模型收到的 content／details／structuredContent 保持既有格式，唯一檔名行為變更為 note 新檔 timestamp。

## 失敗歷程與限制

- 初次 typecheck 遇到 Note 空物件 details 的 inference 與 File 不同 result-details 型別問題；已明確 typing 並重跑通過。
- 初次本地 smoke 缺少 builtin Shell 所需 context.state；probe 已補 state／invalidate，避免啟动 elapsed timer。
- 初次 package／matrix 失敗原因為 production runner 漏複製 renderer-probes.mjs。已補 fixture copy，required tarball resources 明確涵蓋三個新增 renderers；所有原 assertions 保留。初次失敗 logs 與成功 retry logs 均保留，失敗不算通過。
- 單元測試 11 項 Windows-only Shell path probes 在 Linux skip；不宣稱 Windows runtime 通過。
- 本輪只有 Web 顯示層，沒有更動或啟動實際瀏覽器，也沒有 paid backend 請求；未執行 browser:install／test:browser。matrix 是 production smoke，不是每版本完整 source suite、也不是實際 fullscreen／regular 終端視覺驗收。
- Provenance verifies local hashes；原來源目錄不可用，0 originals checked，10 個歷史 delta earlier contents unavailable，不宣稱 original-source equivalence。
- 執行中的 Pi session 在修改前載入 extension；需 `/reload` 或重啟才會使用新 renderer 與 note timestamp。既有筆記（包括本份修改前建立的盤點報告）不更名。
- 所有變更維持未提交、未發布。
