## Warnings (should fix)

### W2 — UTF-8 解碼後的字串相等，不等於宣稱的「完整原始 bytes 未變」

- **嚴重度：Warning；本次新 helper 的完整性契約缺口。**
- **來源：** `modules/subagents/extensions/subagent/child-startup-receipt.ts:3–5,23–24,35,38`。`OwnedReceipt.bytes` 實際是 string，大小用 `Buffer.byteLength()` 核對，但內容以 `fs.readFileSync(fd, "utf8") !== owned.bytes` 比較。文件 `modules/subagents/README.md:281`、`modules/shell-tools/README.md:26` 與 handoff `:18` 宣稱完整 receipt bytes 不變。
- **已直接觀察的程式證據：** 驗證會先將磁碟內容寬鬆 UTF-8 解碼，並未將原始 Buffer 與初次寫入的 Buffer 比較。相同 inode/dev 和相同長度無法彌補解碼非一對一的問題。
- **靜態推論，未在本次執行重現：** 若合法 receipt 的 cwd 或 model 字串包含 literal U+FFFD，初始 JSON UTF-8 含 `EF BF BD`；同 inode 的等長內容變造可把該片段改成截斷四位元組 UTF-8 前綴 `F0 90 80`，緊接原 JSON ASCII 字元。寬鬆解碼可仍產生同一 U+FFFD，使大小與解碼字串檢查均通過，儘管實際 bytes 已變。不需要 symlink、replacement inode 或並行 race。當 receipt 無 U+FFFD 時，不以此反例宣稱其一般 ASCII tampering 也能通過。
- **影響界定：** 這違反「任何 receipt bytes 修改均 fail closed」的精確政策；不是已重現 model/trust 繞過或付費請求，也不應上綱為對抗惡意擴充的安全邊界。model/config/trust 每次仍獨立重驗證。
- **最低建議修正：** 保留 serialized string 作 payload 比較亦可，但檔案驗證應用 `Buffer.from(serialized, "utf8")` 的原始 Buffer、精確 byte length 與 `fs.readFileSync(fd).equals(expectedBuffer)`；不要先容錯解碼再驗完整性。保持 same-object lease、exclusive `wx`、missing 不重建及拒絕不覆寫政策。
- **最低回歸：** 在 receipt unit 建立包含 literal U+FFFD 的合法欄位，完成第一次 valid lease 後做上述同 inode／等長 raw-byte 變造，再用相同 expected object 重驗，須拒絕且保留變造證據；至少另覆蓋一般多位元 Unicode 正向。可再加入 offline actual-host mode，要求實際 close exit 1／admission 0。本 reviewer 未執行此候選回歸，現有 52 targeted 與兩個 module green 未涵蓋它。

## Suggestions (consider)

### S5 — 補充 lstat/open/fstat/read/post-check 間的 deterministic race 回歸，限制「讀取期間未變」措辭

- **嚴重度：Suggestion（回歸覆蓋／契約精確性），不是已重現失敗。**
- **來源：** `modules/subagents/extensions/subagent/child-startup-receipt.ts:18–27`；`modules/subagents/tests/child-startup-receipt.test.ts:10–48`；handoff `:18,28,80`。
- **靜態查核：** 前置 lstat 拒絕非 regular／symlink／外來 dev/ino；open 使用 `O_RDONLY | O_NOFOLLOW`（不可用時為 0）；fstat 核對實際 descriptor 的 regular/dev/ino/size；讀取後 lstat 再核對 path 的 regular／非 symlink／相同身份。即使平台不提供 O_NOFOLLOW，descriptor 與後置 path checks 仍保留，不會僅因 open 成功就接受。inode 0n 明確拒絕，沒有 weak identity fallback。
- **覆蓋限制：** 現有三個 fault units 分別測 close failure、inode unavailable、前置 symlink metadata；actual-host replacement 發生在 reload 前。未見在前置 lstat→open、open→fstat、read→後置 lstat 精確階段切換 path 的回歸，也沒有讀取後再 fstat/size/content mutation 的斷言。後置 lstat 只比身份，不是對整段讀取期間所有 bytes／metadata 都未曾變動的原子證明；成功檢查後的外部寫入亦非此 helper 能永久禁止。
- **最低建議回歸：** 用同步 fs fault injection 在上述階段注入替換／symlink／descriptor identity mismatch，要求拒絕且不寫入、不取得新 lease；若要承諾更強 snapshot semantics，再決定 bounded raw read 與讀後 fstat/size/metadata 策略並測試。不得靠固定 sleep 製造 race，也不要為 Linux/macOS green 弱化 bigint／inode fail-closed。
- **平台界定：** 現有執行證據為 Windows；Linux/macOS 的 O_NOFOLLOW、inode 行為及 race fixture 尚未實測。這是未驗證，不是已知平台失敗。
