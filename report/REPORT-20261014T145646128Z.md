## Critical (must fix)
### F1 — P1：handoff receipt 到 deferred runner 之間 shutdown 會漏取消原 process
- **位置：** `modules/shell-tools/extensions/timeout-ms.ts:257-269`；`modules/shell-tools/src/background-jobs.ts:250-254`、`:473-495`。
- **觸發：** 無 timeout 的前景指令達門檻，submit 建立 job 並排 setImmediate；工具回 receipt、unlink turn abort。若在 deferred runner 執行前進入 session_shutdown／owner invalidation，shutdown 先停止 generation 並 abort job controller；runner 隨後在 isCurrent 檢查直接 throw，根本不進入安裝 onJobAbort 的 callback。
- **影響：** 已啟動的 foreground controller 未收到 abort；registry 可完成清理，但原指令仍持續執行／寫 workspace，且無可用 job 管理。這是漏發取消，不只是 process-tree best-effort 的固有限制。
- **建議：** 接受 adoption 時同步建立 job→原 process 的取消橋接，所有 deferred-start 拒絕／shutdown 路徑也須撤銷或停止原執行；不可先 unlink 再依賴未必會執行的 callback。
- **驗證：** 逐步追蹤上述控制流即可證明橋接缺席；現有 shutdown 測試先 await boundary，handoff fixture 也未覆蓋 receipt 後立即 shutdown。建議以受控 setImmediate／fake backend 驗證此順序，不等待真實門檻。此重現未執行。

## Warnings (should fix)
### F2 — P2：每個輸出 chunk 同步重建整個 retained-jobs UI
- **位置：** `modules/shell-tools/src/background-jobs.ts:292`；`modules/shell-tools/src/live-widget.ts:51-52`；`modules/shell-tools/src/background-panel.ts:82-112`。
- **觸發：** TUI 下高頻輸出；每個 chunk 更新 totalBytes，refresh 對最多32筆含 command/details 的紀錄清理、映射及 JSON 序列化。byte details 每次改變，signature 去重無效，持續呼叫 setWidget 重建元件；即使 log/head 已滿仍如此。
- **影響：** UI 工作與 chunk 數線性增加，佔用處理輸出、abort、timeout 共用的事件迴圈；五筆顯示上限並未限制此重建頻率。實際延遲／CPU幅度未量測。
- **建議：** 事件驅動合併更新，僅有可見摘要變化才重建常駐 widget；詳細 byte 統計按需刷新，保留取消／完成的立即更新與 generation fence。
- **驗證：** live-widget 現有去重測試只有不變 rows；可用受控 N 次 data 及 mock UI 呼叫計數驗證，無需 sleep。未執行。

### F3 — P3：handoff 遺失原始輸出 byte 計數
- **位置：** `modules/shell-tools/src/foreground-handoff.ts:94-99`；`modules/shell-tools/src/background-jobs.ts:259`、`:449-450`。
- **觸發：** 交接前輸出2 MiB、交接後不再輸出。handoff 只重放1 MiB head＋8 KiB tail，job.totalBytes 只累加重放量。
- **影響：** Monitor outputBytes 與 UI「Output bytes observed」顯示1,056,768而非2,097,152；輸出量愈大低估愈嚴重。保留資料有界是正確政策，但觀測計數不應隨丟棄資料縮減。
- **建議：** adoption 傳遞原 totalBytes，與重放資料分開計數，後續只累加新 chunk，避免雙計。
- **驗證：** 現有 handoff 測試只檢查 replay 大小與 tail marker；算術及資料流支持此問題，跨 ShellJobs／Monitor 的計數斷言未執行。
