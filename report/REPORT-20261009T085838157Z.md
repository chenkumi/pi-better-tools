## 身份與生命週期決策

- 不新增 plugin manager，不複製 extension，不以 JSON/RPC/cwd/session 檔或 prompt 推測。
- Parent 經既有 managed admission 後，僅在兩個 owned spawn sites 使用共用 builder。既有 `PI_SUBAGENTS_GUARD` payload 的明確 mode 即私有協定；無獨立持久化格式、設定或憑證副本。
- Shell factory、startup guard（及 Subagents 的共用提示 factory）任一先載入者均可消耗環境；guard 原有 `globalThis.__piSubagentsGuardExpected` process-local copy 保留 mode，與 guard 配置更新同存，reload/resume 同 process 不丟失。新 invocation/ready-query process 重新由 builder 明確傳遞。
- 消耗後 OS shell／手動 nested Pi 不繼承 handshake；不宣稱可以抵擋惡意已安裝 extension、手動仿造環境或 shell 自建背景行程。Process isolation 不是 OS sandbox。
- Child 不建立 ShellJobs，不註冊 shell_job_status/cancel，不啟用任何未選工具；前景仍共享宿主 execution、settings、output、AbortSignal/process-tree termination 委派。
