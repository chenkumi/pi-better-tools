# Fork 面板：終態 cleanup 文字與實際證據矛盾修正

## 缺陷
completed／cancelled 且 `cleanup.childClosed=true`、permit released 的 Fork，More 清單與詳情 State 仍顯示「cleanup unconfirmed · child close not observed」，與同一詳情的「Cleanup: child closed · exit 0」「Permit: released」矛盾。真實 child 已退出，非程序洩漏。

## 原因
`modules/fork/src/live-widget.ts` 的 `activity(job)` 對所有終態無條件回傳未確認文字。

## 修正
終態依證據判定：released 且 `cleanup.childClosed===true` → `<status> · child closed`；permit 仍持有／未確認 → 保留 `cleanup unconfirmed · child close not observed`；released 但無 cleanup 證據（磁碟復原的 interrupted）→ 只顯示狀態，不宣稱任何一方。未改 Fork 啟動／取消／投遞／permit／guard。

- 新增 `modules/fork/tests/live-widget.test.ts` 三案例（completed、cancelled 已關閉；childClosed=false 仍警示）。修正前兩個已關閉案例因斷言 red（actual 為 unconfirmed 文字），修正後 green。
