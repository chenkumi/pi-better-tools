# API 中斷工具卡片顯示修正

## 範圍

在 Shell Tools 註冊公開 registerToolRenderer resolver，覆蓋有 renderer 的工具卡片（包含 file-tools），不改工具選取、execute、content/details/structuredContent、API retry policy、主對話 assistant error 或全域安裝。沒有 shell extension 時不生效；沒有既有 renderer 的工具保留 host fallback。

## 判定與顯示

以 message_end assistant stopReason:error 中的 toolCall ID、實際 execution start/end 事件與 renderer executionStarted 核對。只替換 provider 中斷造成的單一文字、無 details 的合成 error；使用者 aborted 與真正 toolResult 保留。後續 before_provider_request 是 resuming 證據，後續正常 assistant message_end 是 response recovered 證據；不假造官方 retry attempt/倒數/耗盡資訊，不把舊未執行工具算成功。

用 renderShell:self 重建 default 工具原有 Box，維持原 renderCall/renderResult、state、lastComponent、outputPad、images、展開與 timing。原 self-shell 正常路徑沿用；中斷 result 換中性提示，展開保留安全 provider 診斷。事件 requestRender invalidation，無 ticker／輪詢。bounded records，session 更換清除；歷史只依 branch 的中斷／實際結果重建，不推測已恢復。

## 驗證

新增純 regression（事件次序、真工具 error 優先、取消／新 input、重複 retry、session scope、不可變 result、default/self framing 與 delegation）。真實 host ToolExecutionComponent 測試完整卡片背景、窄欄、重画與 images/result renderer preservation，不啟動 provider 或背景 jobs。執行 Shell 模組、npm test 與跨模組分組；同步 README、architecture、provenance。正式退出後才交付，失敗/skip不算通過。
