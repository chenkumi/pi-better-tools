# 跨平台與封裝回歸修正

## 範圍

依使用者指示：封裝測試只要求根 LICENSE，修正 macOS canonical path、平台適用的大 shell payload 測試、Web host-native cwd 契約與 provenance，並執行完整回歸。

- 保留原始模組 copyright／LICENSE 與第三方 notices（不另補缺失的 Shell LICENSE）；本地 File 重複授權檔可移除。根 LICENSE 是整合包驗證必要資源。
- Subagent 僅變更測試／fixture，保留 managed storage、guard、取消與 streaming 安全語意，不修改 runtime lifecycle。
- 不修改全域 settings/auth/排程、不用付費模型；所有 probes 使用現有隔離 home/workspace。
- docs/sources.json 維持 immutable；逐一查核既存差異再寫 adaptations，不以批次重算雜湊掩蓋未查核變更。原始 Windows 文件不在本機，不能宣稱原始逐行 diff 已驗證。

## 工作與驗證

1. 修正 package required 資源，同步授權 notices。
2. canonical path 比較採 realpath 實際檔案，精確要求 transcript 預期位置。
3. large-shell Windows 用 PowerShell，POSIX 用 Bash 執行 Node 輸出相同 600 KiB；保留成功、truncation、大 payload 不膨脹 transcript 的斷言。
4. Web cwd 測試使用 host-native 路徑並加入 POSIX literal backslash 案例，不變更 runtime settings／log key。
5. 查核七個既存 provenance 差異與本輪變動，記錄原因與缺少原始來源比對限制。
6. 執行 build/typecheck/unit/integration/browser/package/sources，以及 Pi 0.99.1/0.99.2/1.0.0 production matrix。未執行與 skip 不算通過。
