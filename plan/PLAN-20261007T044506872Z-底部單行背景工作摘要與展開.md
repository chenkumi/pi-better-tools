## 決策

保留兩個 registry／owner／canonical-cwd／epoch／取消與通知語意，仍由既有事件驅動 projection。新增純 presentation helper `modules/shell-tools/src/background-panel.ts`，兩個 adapter 共用，不建立 plugin manager、全域 registry、poll/ticker、跨行程搜尋或 provider 工作。共享只經公開 pi.events 的同步 rendezvous（runtime 自動清理 subscriptions），不用 module-global singleton／WeakMap 假設；SDK 1.0.0 每 extension events wrapper 不同，reload 先 invalidate 舊 runtime。helper 位於既有 tarball files 路徑，沒有新 entry／依賴。此為刻意新增的跨模組 UI 依賴，須記錄於 architecture／provenance。

收合只顯示數量，不泄露 command/title。Subagents 數量為 queued/running tasks，不把 finalizing batch 偽裝成執行中的 child；finalizing 可點開看明細，即使摘要為0。取消中仍計數直到 registry 終結。展開沿用既有安全／有界明細，狀態與短ID保留；controls/ANSI/bidi、Unicode欄寬、顏色重算與SGR reset保持。窄終端縮寫兩個 label 並維持一行，點擊範圍依實際終端欄位計算；只有header的左鍵單擊操作，wheel/drag/右鍵/修飾鍵不攔截，no focus request。旧 component dispose／replaced generation／owner失效不能切換新面板。
