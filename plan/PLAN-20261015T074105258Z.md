## 已發現的適配需求

來源使用 Pi 0.85.1，整合基準只支援 1.2.0。來源 runtime 頂層 require MSSQL ODBC native driver，與本專案 ignore-scripts／跨平台載入不合；會最小改成 Windows Authentication 使用時才 require。來源 prompt 全文替換改為共用 deferred hint + tool-specific guidance。原始 SQL policy／output／config helpers 原則上保持 byte-identical。

本次使用 Windows／Node v26.8.1。初次證據在 `plan/evidence/sql-connector-integration/`；最終證據在 `plan/evidence/sql-connector-integration-final/`。不修改原專案或使用者真實設定。

## 最終實作

- 入口 `modules/sql-connector/src/index.ts`，放在 Pi Runtime 前面，讓 trusted project 已配置引擎的動態工具在 startup fallback 前註冊。
- mysql／mssql／pgsql 各三個 state/query/update 工具，全部 deferred。Runtime 統一提供短 discovery hint；原有參數／安全 guidance 由載入後的 state 工具 promptGuidelines 提供，不再替換整份 system prompt。
- Source config/types/prompt/output/SQL policy 與兩個純來源測試、分享 example 均 byte-identical。Runtime 差異經逐字比對，僅移除頂層 ODBC require 並移至 Windows Authentication constructor；其他 driver、binding、pool 與取消程式不改。
- 根 npm install --ignore-scripts 完成，新增固定 source-lock 版本 mysql2/mssql/pg、optional msnodesqlv8 與型別；唯一 lockfile 已更新。沒有執行 ODBC native rebuild 或系統 driver 安裝。
- Manifest 為 16 local + 2 npm entries，共 18；files、package required resources、README/configuration/architecture/migration 與 provenance 已同步。Pi Runtime 本身只有 README 變更，既有 cross-tool-guidance 保留。
