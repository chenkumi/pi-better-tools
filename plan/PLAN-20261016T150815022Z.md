## 已確認決策與邊界
- Chromium 或明確設定的 Chrome 可用時保留原行為；只有明確 executable 缺少才 HTTP fallback。不因權限、啟動 timeout、網站錯誤、TLS、網路政策拒絕而切換重試。
- 保留工具參數及既有 channel，第一階段不新增公開模式設定、不自動改 channel、不處理 npm playwright 套件遺失。
- HTTP 不執行 JS、不載入 subresources；有 waitForSelector 時明確拒絕無法履行的降級。結果需警告靜態擷取限制。
- 兩條路徑共用 queue、總 deadline、取消與抽取 worker；不永久快取缺瀏覽器失敗。
- HTTP transport 必須逐跳驗證公開位址並綁定已驗證 DNS 到實際連線，保持 hostname TLS/SNI、串流大小限制及 cleanup。實作前選擇最小可驗證方案：受控 node:http/https，或明確直接依賴的 scoped dispatcher；不得修改全域 dispatcher。瀏覽器既有 DNS rebinding 限制不得誇大為已修復。
- 公開 CLI 預定提供 doctor、browser install、browser install-deps、pty setup。從自身位置解析依賴，不依賴 cwd 或全域另一版 Playwright；以 package bin 暴露，打包 files 包含完整入口與 helpers。
- doctor 只讀、不探測付費 provider／資料庫；安裝命令不在 postinstall、reload 或工具呼叫時自動執行。browser install-deps 只由使用者明確執行，本次不得自動安裝 OS 套件。
- Runtime 指令提示須指向實際安裝實例，可使用目前 Node＋CLI 的絕對路徑，正確處理 Windows／POSIX quoting；不要以 npx 任意抓最新版代替。
- 原開發 scripts 可保留為正式實作的薄入口；PTY native setup 保留 project approval，不修改全域 npm policy。
- skill 目錄須可獨立搬移，必要說明存於 skill 內部 references；不連結 repository README 取代內建說明。
- 不 npm publish、不 push、不改真實全域 settings/auth/排程、不移除真實 browser cache、不呼叫付費模型。
