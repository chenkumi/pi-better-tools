# Subagent title：實作與驗證紀錄

## 需求與決策
- 使用者要求派遣新增 title，描述「用50字內描述這個subagent要做甚麼事」，並於TUI顯示。
- 選填以保持舊呼叫相容。頂層title支援single/resume與批次總標題；tasks/chain每項可填title，優先於頂層fallback。
- 最終採最多50 Unicode code points（碼點，非UTF-16 units；組合emoji／重音可含多個碼點），schema maxLength50與execute前驗證；不接受空白／控制碼-only標題。Renderer防禦性限長與清理ANSI/C0/C1/bidi，不變模型task／child args／managed配置、鎖、guard、信任或儲存格式。
