# Blackhole 本地快照與最後回答顯示修正

## 使用者授權與範圍

使用者要求維持 Blackhole，把 C:/GitHub/pi-blackhole 程式碼複製至 pi-better-tools，改掛載專案內入口，修正已發現的問題。基準來源 0.5.12 / a2e4c13；本專案先前安裝 0.5.11。既有 working tree 大量未提交修改是前置狀態，不清除、不回退、不納入本輪成果宣稱。

## 方案

1. 匯入 modules/blackhole：完整 runtime src、原 index.ts、來源 tests/config/docs/README/CHANGELOG/LICENSE 與來源 manifest metadata。排除 .git、node_modules、lockfile、私人 .pi 與 work_docs；根唯一 lockfile。入口 modules/blackhole/src/index.ts 為薄轉接，不 bundle host SDK。
2. 根 package manifest 以 local Blackhole 入口取代 node_modules/pi-blackhole/dist/index.js，移除 pi-blackhole npm dependency、更新 root lockfile，保留另外兩個 npm extensions。全域 Pi packages 已只掛載 pi-better-tools 根目錄，無 standalone Blackhole，故修改根 manifest 即可切換，不新增或改寫真實全域 settings/auth。
3. 先加入 oldest-first chronological branch regression 並執行 red；修正 cosmetic-output selector 從 compaction 前一筆往前走，bounded scan、16KiB/ANSI/idempotency/display-only/config guards 保持不變，修正原測試錯誤的 branch mocks 並 green。
4. 驗證 append 的 display-only copy 可持久化／resume 且不進 provider context。未授權改變摘要裁切策略或壓縮時機，保留 midRunCompaction=off 等真實設定；此修正不讓 resume 顯示所有舊原始對話、不自動補已壓縮的舊 session。
5. 同步 README、migration/configuration/architecture、third-party notices、AGENTS 模組資訊與 provenance。來源檔 original SHA 與本地 adaptations 分開記錄。
