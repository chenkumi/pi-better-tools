# 背景工作證據與提前停止模型規則

## 目標

在 Shell／Subagents 原生 extension 的 before_agent_start 注入同一份可去重 system prompt section，而不是依賴專案 AGENTS.md 或完成通知的資料前言。

規則區分 log／snapshot 暫定結論與 runner 終結證據，通知順序不等於完成順序；不再需要的 owned 工作須透過既有取消工具停止並核對收尾，必要驗證／commit／cleanup 不應因早期 pass 被中断。未選管理工具不得暗中啟用／使用其他方式亂殺行程；無取消路徑時明說限制，預先優先使用前景。

## 範圍

新增 Shell src 純 helper 與單元測試，Shell／Subagents factory 呼叫共享 helper，沿用既有 child guards、ownership、followUp、取消／cleanup 與工具 loadout。不實作從任意輸出文字自動取消、不新增 daemon／settings、不修改真實 settings/auth。
