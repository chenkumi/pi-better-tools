# Managed Subagent 專用前景 Shell 工具定義

## 使用者授權
使用者要求依先前建議實作：managed subagent 的 bash/powershell tool definition 不提供 background 參數，主 agent 保留現有非同步 Shell；可委派實作，最後獨立審查成果。

## 契約
- 相同工具名称，共用執行核心；不複製整份 Shell extension。
- managed child schema 僅 command/timeoutMs，description/guidelines/output schema 不介紹或容納背景receipt。
- child 不提供 shell_job_status/shell_job_cancel，不能暗中啟用任何工具。
- 執行端拒絕 child 外來 background 參數，不默默轉換或啟動背景工作。
- 明確 child identity，不以 RPC/JSON模式或 cwd 推測；與既有 guard/child argument builder 整合，考慮載入順序、reload、resume與ready-query。
- 主 agent schema/背景管理/timeout/取消/設定/trust/credentials 保持原樣。
- 不宣稱此限制能阻止命令自身detach，也不構成OS sandbox。

## 執行
單一實作 worker 擁有 modules/shell-tools/ 與 modules/subagents/ 的變更權，其他檔案由父agent處理；先閱讀README/AGENTS及Pi extension文件，補回歸確認red/green。禁止真實provider與個人設定；實作 worker 自身不得使用背景Shell。

## 驗證與交付
針對child schema/執行端/管理工具不可用及main保持相容建立純單元和離線真實host證據。父agent更新相關根docs/provenance，執行涉及的兩模組分組、根unit/typecheck與cross；獨立reviewer唯讀復審。未執行項目、skip/阻礙均明示；不自動重跑前runtime結果未知工作。

## 非目標
不在此輪修正十三項Blackhole共存靜態審查的其他發現；不改壓縮時機/個人設定/排程/歷史session；不發布或commit。
