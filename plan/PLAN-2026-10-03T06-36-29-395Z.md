# Subagent 模型／思考等級預檢與容錯

## 範圍與決定
- 更新 model／provider／thinkingLevel 描述及 prompt guidelines：預設省略呼叫 override，只有使用者或 skill 明確指定才傳入。不代表停止正常繼承 parent 預設模型。
- 新派遣先解析模型，再驗證該模型支援的 thinkingLevel；未知／歧義模型 override 與未知／不支援等級忽略，按原本預設規則執行。
- 明確 provider 僅查詢其 exact model ID；單一模型字串優先註冊的 provider/model 解讀，否則查完整 exact bare ID（優先目前 provider，否則唯一匹配）；不猜測模型。省略／忽略模型 override 時保留可用 agent 模型 → parent 模型；有效 override 且無有效 thinking override 時保留 child 預設思考設定。繼承 parent 的思考等級按最終模型使用 host clamp，避免要求與有效等級不一致。
- thinkingLevel 接受字串、在執行前驗證；否則未知等級會先被 enum schema 擋住，無法履行使用者要求的忽略行為。
- 保留 resume 的已保存配置、strict registry/trust/checkpoint 驗證、child startup guard 與既有生命周期。父程序 registry 可用不代表 child provider 一定能載入，也不證明遠端憑證或模型 API 可用。
- 不修改既有 session、全域設定／憑證；不呼叫付費模型。
