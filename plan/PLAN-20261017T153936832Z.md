# 真實 API 測試計畫：native（Gemini）／DeepSeek REST／Anthropic Phase 2 決定點

日期：2026-10-17
對象：`modules/web-tools`（本地 package，`pi list` 確認載入路徑即 `C:\GitHub\pi-better-tools`）
前置事實（已查證）：
- `pi auth check --provider {anthropic,google,deepseek} --json --no-refresh` → 三者 `status: ready`、`authType: api_key`。
- Pi 1.3.0 有 `--print/-p`（非互動）、`--mode json`、`--session-dir`、`--no-session`、`--api-key`、`-ne/-ns/-np/-nc`、`-t/-xt`。
- `before_provider_request` handler 會依序串接（runner `emitBeforeProviderRequest`：handler 回傳值成為下一個的 `event.payload`）→ 可掛唯讀 observer 取得最終 payload。

## 一、目標

1. 驗證本回合新增的兩個模式在**真實 provider** 上可用：`provider: "native"`（Gemini 3/4 grounding）、`provider: "deepseek"`（standalone Search API + Pi 憑證）。
2. 取得**決定性證據**回答 Phase 2 唯一的阻塞問題：Anthropic 的 `server_tool_use`／`web_search_tool_result` 若被剝除，下一輪是否真的 400。
3. 全程不改使用者真實設定、不洩漏金鑰、成本可預期（總額上限約 US$0.5）。

## 二、測試環境與規則

- **啟動方式**：`pty_spawn` 於 `cwd=C:\GitHub\pi-better-tools` 啟動 `pi`（載入本地當前原始碼）。需要觀察 TUI／`/web-tools status` 時用互動 session；需要精確輸出時用 `pi -p --mode json`（同一份程式碼，差別只在輸出模式）。
- **設定隔離**：一律 `PI_WEB_TOOLS_CONFIG=<OS temp 絕對路徑>`（模組支援此環境變數），**不動** `~/.pi/agent/web-search.json`（目前是 `provider: brave`）。測試前後各記一次該檔 sha256 證明未變。
- **Session 隔離**：`--session-dir <temp>/sessions`；純觀察案例再加 `--no-session`。不寫入使用者的 `sessions/`。
- **憑證**：只用 Pi 已存的 login（由宿主解析），不設定、不列印、不複製任何金鑰到 repo 或 log。觀察器只記 payload 的**欄位／keys**，不記 headers、不記 auth。
- **其他噪音抑制**：`-nc`（不載入 AGENTS.md）、`-ns`、`-np`；`-t web_search,web_fetch,read` 限定工具集（Gemini 案例仍有 function declarations，足以測混用）。
- **證據位置**：`<temp>/pi-ws-test/evidence/*.json`（原始）＋本計畫的驗證紀錄（去識別後）。付費探針腳本放 OS temp，不進 repo（避免違反「不呼叫付費模型」的 CI 規則）。
- **成本假設**：Gemini grounding Gemini 3 起每 query $14/1000（含每月 5,000 次免費）；Anthropic web search $10/1000；DeepSeek Search $0.75/1000 + token 費。

  ```ts
  import { appendFileSync } from 'node:fs';
  export default function (pi) {
    pi.on('before_provider_request', (event, ctx) => {
      const p = event.payload ?? {};
      const tools = Array.isArray(p.tools) ? p.tools : Array.isArray(p.config?.tools) ? p.config.tools : [];
      appendFileSync(process.env.PI_PAYLOAD_LOG, JSON.stringify({
        api: ctx.model?.api, provider: ctx.model?.provider, model: ctx.model?.id,
        toolNames: tools.map(t => t?.type ?? t?.name).slice(0, 40),
        googleSearch: tools.some(t => t && t.googleSearch !== undefined),
        includeServerSideToolInvocations: p.config?.toolConfig?.includeServerSideToolInvocations === true,
        nativeOpenAi: tools.some(t => t?.type === 'web_search' || t?.type === 'web_search_preview'),
        anthropicNative: tools.some(t => typeof t?.type === 'string' && t.type.startsWith('web_search_')),
        topKeys: Object.keys(p).sort(),
      }) + '\n');
    });
  }
  ```

### Step 2（補跑，2026-10-17 帳號充值後）：Gemini 已驗證可用

- **S2.1**：`google/gemini-3.8-flash` + `native.json` + 真實憑證 → payload `googleSearch: true`、`includeServerSideToolInvocations: true`，**無 400**；回答帶真實 URL。花費 tokens $0.0093。
- **S2.2**：`google/gemini-4-argon` 同條件 → **無 400**；並且 observer 在 `provider_stream_event` 收到 `kind: "grounding"`：`webSearchQueries: ["F1 drivers standings 2026"]`、`groundingChunkCount: 2`（hosts 均為 `vertexaisearch.cloud.google.com`）→ **確實觸發了 grounding**，回答引用了 grounding redirect URL。花費 tokens $0.0049。
- **重要細節**：S2.1 那次沒有任何 grounding 記錄 → 模型**自己決定不搜尋**（它寫的是 `https://www.formula1.com` 首頁，不是 grounding redirect）。所以「請求被接受（200）」**不**等於「有搜尋」；引用 Google 官方文件時要分清兩者。
- **額外的獨立探針**（不經 Pi，直打 `generateContent` 與 `streamGenerateContent?alt=sse`）：兩者都回 200 且 `candidates[0].groundingMetadata` 存在（串流 8 個 chunk 中有 1 個帶）。所以 `groundingMetadata` 不是被 Pi 的 SDK 丟掉，只是不在每個 chunk 上，且本模組的 observer 確實拿得到。這打開了「像 OpenAI `captureSources` 一樣為 Gemini 保存來源」的可行性（未實作）。
- 花費小計：Gemini 本回合 ≈ $0.02–0.05（搜尋部分可能落在每月 5,000 次的 Gemini 3 免費額度內，我們看不到帳務明細）。

#### 探針腳本（OS temp，不進 repo）

- `gemini-probe.mjs`：非串流 `generateContent`，驗證 API 接受 camelCase `googleSearch` 並回傳 groundingMetadata。
- `gemini-probe-stream.mjs`：`streamGenerateContent?alt=sse`，逐 chunk 確認 groundingMetadata 出現在哪裡。

### Step 4：Anthropic 多輪結論——**不需要 block replay**（已驗證）

模型 `claude-haiku-4-5`，`tools: [{type:"web_search_20250305",name:"web_search",max_uses:2}]`，原始回應存於 `<temp>/pi-ws-test/evidence/s4_*.json`：

| 請求 | 狀態 | 頡察 |
| --- | --- | --- |
| R1 初次（帶 search tool） | **200** | blocks `server_tool_use` → `web_search_tool_result`（含 `encrypted_content`）→ `text`×2；`usage.server_tool_use.web_search_requests: 1`；text 帶 `web_search_result_location` citations |
| R2 原樣回送（對照） | **200** | 模型仍保有檢索上下文（追問也有 citations） |
| R3 **剝除 server blocks（= Pi 現在的行為）** | **200** | 只有 text 時 API **接受**；代價是後續 pill 不再有檢索上下文與 citations |
