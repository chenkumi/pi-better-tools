## 分類指引

1. Chromium executable 缺少：以相同 user/cache 環境執行 `npm run browser:install`。
2. Chrome executable 缺少：安裝 Google Chrome，或明確改用 chromium channel 並安裝；不自動切換。
3. 系統依賴缺失：Linux/WSL 經使用者同意後執行 `npm run browser:install-deps`；其他平台檢查 runtime dependencies。
4. Permission denied：檢查 executable/cache 權限與 OS policy，不直接要求重裝。
5. Launch timeout：檢查系統負載、啟動限制與 fetch.timeoutMs，不推論缺少 executable。
6. 其他失敗：說明未確認 browser 缺失，檢查 runtime compatibility、policy、resources。
