# PTY 整合與跨平台 target

## 範圍
- 將使用者擁有的 C:/GitHub/pi-pty-terminal 來源快照匯入 modules/pty-terminal；不修改來源、不新增獨立安裝單元。
- 原七個工具保留；pty_spawn 新增 target（預設 local）；WSL/SSH named targets 由 Pi trust-aware settings 的 pi-pty-terminal.targets 提供。
- 非 local cwd/env 指目標環境；安全 POSIX quoting，WSL 限 Windows，SSH 保留 host-key 驗證且採 BatchMode，不退回 local。
- session metadata 顯示 target/transport、本機 PID；關閉 transport 不宣稱遠端 process tree 已停止。
- Git 同步與非互動執行不在本次範圍；不連真實 SSH、不讀寫真實 auth/settings。

## 步驟與驗收
1. 匯入來源、授權與 baseline hashes；根 manifest/dependencies/runner/package probes 整合。
2. 實作 target resolver 與測試（local 相容、WSL argv、SSH quoting/cwd/env、invalid config、安全與取消）。
3. 原 PTY 真實測試改為平台原生 Node fixture，保留互動/exit/drain 斷言。
4. README/configuration/architecture/migration/provenance 同步。
5. 執行 build/typecheck/unit/integration/package；記錄實際失敗、skip 與未驗證的 WSL/macOS 真實端點。
