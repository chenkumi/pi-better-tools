# Shell 終端輸出 TUI 排列調整

## 需求與範圍

- bash／powershell 的終端輸出每個實際顯示行以 `▌` 標示，包含空白行與折行。
- 收合維持最後五個 visual rows；`N earlier lines, <目前快捷鍵> to expand` 移至輸出下方、宿主警告與 Took／Elapsed 上方，前後留白。
- 展開保留輸出 rail、不顯示省略提示；不改命令、模型結果、session、timeout、取消或背景工作生命週期。

## 首次失敗與修正說明

- 初版直接處理宿主縮短後的 hint，在窄欄無法取得完整行數；改依宿主完整 sanitized Text 的實際折行數計算，不再解析 hint。
- 測試需區分 ANSI／terminal padding 與文字；窄欄可合法截短提示，不禁止提示尾端的 truncation marker。
- 0／1 欄只斷言本次適配的輸出 component 寬度；未修改宿主 warning／timer Text 的既有 minimum-width 行為。
- 本地目錄無可用 Git metadata，`git status` 無法取得 diff；未初始化 Git 或修改 repository metadata。
