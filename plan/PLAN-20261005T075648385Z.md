## 已完成（延續 phase 1，不再停於背景 status/cancel）

- 同步預設維持 JSON print；`background:true` 的 single／parallel／chain／resume 改由既有 argument builder 啟動 RPC + 獨立 IPC bridge。保留 startup guard、managed writer lock、32 submitted／8 active-child permits、stdin callback backpressure、stdout LF framing、native/wire digest／checkpoint／rollback。RPC 無 header，改驗 get_state 的 session ID/native path/model/thinking、guard 與 get_entries canonical startup prefix。
- `subagent_message({jobId,taskId,mode:"control"|"query",message})` 僅限 exact active task、同 owner/canonical cwd/runtime generation；queued/settled/finalizing 不復活。非空白文字上限 64 KiB UTF-8。
- Control 回 accepted messageId；RPC one-at-a-time steer FIFO 使用 `[Delegated user control <id>]\n<literal text>`，不把 raw slash/skill/template 或 @file 當指令。Ack queued 不算 applied；exact canonical user event 才確認 applied（timestamp/userOrdinal）並 parent followUp。結束時未消費回 not_applied／delivery_unknown。前綴及原文同時進入 wire/native 主線，managed digest 不放寬。
- Query 回 accepted queryId；child bridge 同步取得 canonical header/entries/leaf，拒絕 branch/leaf 不一致，擷取最新完整配對工具 prefix，再用 isolated SessionManager.inMemory 重建 system/compaction/context_edit。驗證 inMemory 確實 replay entries/leaf，避免舊 host 忽略第三參數而用空白 context。保留 opaque metadata；清掉每個 system checkpoint toolsAdded/toolsRemoved。以 child 自己的 modelRegistry.streamSimple、verified model/provider/thinking/trust 呼叫，不用 parent fallback，不跑 main hooks/tools，不 fork/native append/改 leaf。答案只走 token-bound IPC，沒有任意 stdout print。
- Query asOf 含 safe entry/time、source leaf/time、sourceTurn user/assistant ordinal、stale/pending-tool count/IDs/control IDs；獨立 usage，不加入 main/host totals。沒有 terminal usage 時 usageUnknown，不是假零。Provider tool call 直接 failed，絕不 dispatch。
- Query 同 job 2 concurrent/32 retained、process-wide 8 concurrent；invocation 32 controls。逾期／送出不確定時 cleanupPending 並保留 lease，直到 terminal IPC 或 child transport close；晚到 usage 同 queryId 以 lateUsage 校正，不復活過期答案、不累加重複通知。每 query 30 秒、2048 requested tokens、64 KiB streamed output、8 KiB retained answer，IPC envelope 128 KiB，snapshot 8 MiB/16384 entries；RPC 16 pending/8 MiB/30 秒。
- agent_settled 停止新互動，已接受 queries 有獨立期限，隨後關 stdin orderly exit，再 commit。取消先 abort query API/EOF，1 秒 shutdown grace 後沿用 kill escalation。owner replacement/shutdown 抑制舊 callbacks，15 秒 bounded cleanup。Retained jobs/tasks 只保存 plain receipts，不保留 exited ChildProcess/完整 runner context；interaction notifications 不反覆複製整批 query answers。
- README 移除 phase-one-only 宣告，記錄完整契約與限制；新背景互動實測 Pi 1.0.0，0.99.1/0.99.2 未驗證，不用 wildcard peers 宣稱相容。
