# Fork 輸入欄上方動態狀態面板計畫

## Title
Fork 接入共用 Background Jobs 面板

## Goal
讓目前來源 session 建立、尚未完成或清理未確認的 Fork，自動在輸入欄上方顯示任務標題與即時生命週期狀態，與 Subagents／Shell 共用既有 Jobs 面板及 More 浮層。以事件驅動更新，不輪詢、不改變 Fork 的執行、取消及結果回報契約。

## 範圍與決策
- 本輪「動態」指既有 Fork 生命週期事件的即時顯示；工具名稱／串流輸出活動與執行中 token 統計不納入，另行授權後再擴充 child RPC。
- 使用現有 `BackgroundPanel` 與 `PanelJob`；擴充 `PanelKind` 加入 `fork`，不建立新 plugin manager、不搬移共用 helper、不合併 job registry。
- 三種類合計仍最多顯示五個 job、每個兩行，沿用窄欄截短、高度限制、More 與 collapse 行為。
- 面板使用 Fork 標籤、任務 title、短 ID、狀態與用量。尚未回報用量顯示 pending，未知顯示 unknown，不能冒充零或計入繼承歷史。
- Fork `active` 投影包含未終結狀態或尚未釋放 permit；終態但 child close 未確認時，明示 cleanup 未確認，不偽造 running 或 completed cleanup。
- 清理已確認的終結工作移出常駐面板，仍可在 More 查閱當前保留的紀錄；不是跨行程接管或重跑。
- 只在 TUI＋hasUI 掛面板。來源 session ID、native file、canonical cwd 與目前 binding 相符才呈現；session replacement 清除舊展示、切回來源 session 重建。
- 移除 Fork 自己重複的 footer 摘要並清除 `pi-fork` 舊 key；不移除其他模組的 status/widget。
- 不改工具名稱/schema、metadata 儲存格式、快照時機、child guard、結果投遞、取消流程與 permit 釋放條件。
