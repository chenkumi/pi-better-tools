# 背景工作即時 TUI 面板

使用者要求可直接看到正在運作的Subagents／Bash／PowerShell。新增兩個獨立aboveEditor widget，使用原生工具背景色塊，空清單隱藏；不建立跨模組manager或改工具選取／模型資料／通知。事件驅動，不poll、不新增ticker或provider呼叫。Shell列出所有最多8個running/cancelling工作、命令及短ID。Subagents列出最多8個優先running的task（agent、title、job/task短ID、queued/running）；其他數量明示，task已完但batch尚未settled時標finalizing。狀態表示既有registry觀測，不聲稱程序樹或provider已停止。

UI projection僅包含label/status/ID，Subagents title只存private job metadata，不加入既有receipt/content/structuredContent。owner/session/canonical cwd/epoch過濾。接受、admission/live、task finish、batch finish、cancel、shutdown觸發observer；observer或UI錯誤不能改工作成敗／取消／通知。shutdown先清面板，late callbacks不重新顯示。只在tui且hasUI綁widget，不在RPC/JSON/print使用。

欄寬/ANSI/control/bidi/長文字防護沿用TUI helpers，screen列數有界；不顯示output/log正文/控制與query文本。source callback無資源timer；主題每次render重算。已有完成色塊與foreground TUI不變。
