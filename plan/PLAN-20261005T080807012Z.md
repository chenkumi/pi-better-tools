# Subagents reviewer 修復與驗證交接

## 已完成

1. `RpcInteraction.settled()` 不再把 sent + queued 卻無 exact canonical correlation 的 control 宣稱為 not_applied。合法 input hook transform（連 correlation 前綴一起移除）後，回報 delivery_unknown，避免 parent 據此自動重送。只有未送出或明確 handled disposition 才回報 not_applied；未知 disposition fail closed 為 delivery_unknown。applied 仍須 exact canonical event。
2. `RpcInteraction.close()` 現在只關 admission、結束 receipts／RPC requests 並送 query cancel；cleanupPending 與 process-wide/per-task active leases 不因 runner abandon 而釋放。constructor 綁定真正 ChildProcess close event，只有該事件或 token-authenticated terminal query IPC 才釋放租約。`index.ts` abandon→settle→rpc.close 路徑不必改動：close 的新語意不再宣稱 childGone／資源消失。實際 close 的 accepted receipt 直接以 cleanupPending:false 結束。
3. Child query 收到第一個 toolcall_start／toolcall_delta／toolcall_end 即 abort，工具 delta 也計入 output bytes。繼續 drain 到 terminal evidence 再回覆 QUERY_TOOLS_FORBIDDEN；沒有 terminal usage 就 usageUnknown:true，不執行工具、不污染主線。
4. Background notification callback 拋錯時，不再僅吞例外後繼續背景工作；同步關閉 admission／取消 owned jobs／切換 generation，抑制後續 callback。README 說明 SDK 必須 await AgentSessionRuntime.dispose()；直接 session.dispose() 不發送 extension shutdown。callback 不拋錯但宿主已失效的情況無法由 extension 自行偵測。
