# 新增原生 pi-runtime：有上限的錯誤回饋與恢復

## 範圍

使用者要求建立 `modules/pi-runtime/`。採 root manifest 直接 TypeScript entry `./modules/pi-runtime/src/index.ts`，新增原生模組而非 patch／bundle Pi SDK；維持 Pi 1.1.0、MIT、root dependencies/lockfile。原本十個本地入口變十一個，兩個 npm 入口不變。不改個人設定／credentials／其他既有 dirty 工作。

## 行為

- 一般明確可修正輸入類 API error：在 agent_before_settle 用官方 custom_message draft 回饋診斷，request 一次 continuation，與 builtin transient retry／context recovery 分開。
- 默认每個頂層使用者任務最多 2 次恢復；同樣診斷自動恢復一次後重複則停止。後續 extension/followUp／compaction／reload 不重新補額度；active branch 選 task，session-wide 同 task reservations 保留 budget floor，tree／reload 不退回其他分支的已消耗額度。取消及 owner/runtime 更換優先，不在 agent_settled inline 啟動模型。
- Cyber／policy error 不自動重試或改寫：只保留診斷與人工待確認狀態；`/runtime-recover <合法用途與授權範圍澄清>` 必須 idle、有 UI、使用者確認且 budget 未耗盡，才能把透明診斷／澄清加入下一次請求。不代表解除 API safeguard 或授予工具權限。
- Auth／billing／quota／context／transient 由既有宿主／操作人員處理；未知錯誤 fail closed，只接受人工 review。No-session 不自動恢復；不偽造成功，不修改原失敗訊息，不執行 error partial tool calls，不新增 provider/model fallback 或工具啟用。
- 錯誤視為不可信資料、長度 bounded 並遮罩常見 secret 格式。有限预算先保留，沒有 delivery-ack 或 exactly-once 宣稱。提供 `/runtime-recovery status|on|off`，只管理session行為。

## 驗證

先 unit red；新增 classifier／budget／repeat／abort／manual deny/noUI／foreign／reentry／reload/branch 的純回歸。離線實際 Pi 1.1.0 host：error→diagnostic→成功、連續不同error最多2次、重複停止、policy無自动provider續接、人工確認、取消與reload保持額度；隔離HOME/credentials，network/provider禁止。新增module typecheck/unit/host owner，根 unit、cross、build及因入口/tarball改動的package smoke，並同步README/docs/native provenance。Skip／未執行不算通過；長script輸出英文heartbeat。

## 非目標

不自動規避政策、不改 compaction timing、不回寫歷史session、不restore已取消process、不修改其他moduleruntime、不發布/commit。將中間失敗、最終證據、独立review與未完成項目補入本plan。
