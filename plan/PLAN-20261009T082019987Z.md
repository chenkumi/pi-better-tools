# 各模組與 Blackhole 壓縮相容性獨立審查

## 目標
逐一審查根 manifest 的十一個本地模組與兩個 npm 擴充，判斷是否與 vendored Blackhole 0.5.12、實際安裝 Pi 1.1.0 的壓縮／resume 機制相容。

## 方法
每個模組由独立 reviewer 唯讀審查，閱讀該模組 README／AGENTS、來源與現有測試，並追蹤 Blackhole 消費端及必要 host 原始碼。禁止修改程式、個人設定、session、credentials；禁止真實 provider 請求及自動重跑既有背景工作。報告由 note 保存，回傳簡短結論與路徑。

## 審查維度
- 訊息角色與 toolCall/toolResult 配對、custom 與 custom_message 差异。
- 壓縮摘要／recall／工具與檔案擷取是否理解該工具 schema。
- token 或輸出大小、截斷後證據與持久化原始資料。
- 壓縮、resume、reload、tree 與 owner／generation／lease 狀態。
- 背景結果、排程、PTY 與恢復 continuation 的生命週期競態。
- 中途 inline 壓縮及任務结束壓縮，不將設定上的 off 誤認為支援所有模式。
- 既有測試真正覆蓋哪些跨模組互動，未執行與静態推論不得稱通過。

## 交付
逐模組列出結論、具體來源行號、可重現缺口及建議驗證；另彙整共同 host／Blackhole 風險。這是審查，不自動修正。

## 既有工作
前一 runtime 的 pi-runtime 根驗證／production package／全模組整合工作結果不明；不自動重啟、不宣稱已停止或已通過。已知 pi-runtime 上次安全復審未放行，新增修正尚待最終證據。
