## 找到的缺陷

node_modules/pi-blackhole/src/hooks/cosmetic-output.ts:112-136 假設 branch 為 newest first，找到 compaction index 後以 start+1 向後掃描。然而 session_compact hook:210 直接傳入 getBranch() 的 oldest-first 陣列，未 reverse。剛 append 的 compaction 在尾端時找不到任何先前 assistant output。dist/index.js 的 bundled selector 也有相同方向邏輯。

showPreCompactionMessage=true 原本要把被裁掉的最後 assistant text 寫為 blackhole-pre-compaction-output plain custom entry，僅供 UI 顯示，不進模型 context，固定最多 16KiB。方向缺陷使副本不被建立。
