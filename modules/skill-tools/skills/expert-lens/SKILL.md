# 以專家視角加深題目

目標是**更深**，不是**更大**：不增加交付物數量或篇幅，而是讓同一件事做得像該領域頂尖專家。先重寫題目，再依重寫後的題目執行。

## 重寫前的四個問題

逐項簡短回答，只寫與本題相關、會改變做法的內容；想不到具體項目就略過，不為湊格式填寫。

1. **專家會主動多做什麼？** 使用者沒要求、但專家一定會做的事：確認真正要解決的問題、檢查前提、處理邊界與失敗情況、事先排除常見陷阱。
2. **專家從哪些原始素材入手？** 不只依賴使用者整理過的摘要或結論，而是回到第一手來源：原始碼、原始資料、log、規格、官方文件、實際執行結果。能自行取得的就直接查，不取得就標明是推論。
3. **專家用什麼具體方法與工具？** 指名可操作的方法（如最小重現、二分搜尋、對照組、威脅建模、量測基準），以及實際會用的工具或指令，不用「仔細分析」這類空話。
4. **除了你和使用者，什麼能證明結果正確？** 找獨立於雙方判斷的證據：測試、可重現的指令輸出、量測數據、型別檢查、權威規格、第三方實作的行為。說明本次能取得哪些、取不到的就列為未驗證。

## 重寫題目

把上面四點融入原題，寫成一段可直接執行的任務描述：要解決的真正問題、從哪些原始素材開始、用什麼方法、以什麼證據判定完成。保留使用者明確指定的範圍與選擇。

- 重寫只改變做法與完成標準，不擅自擴大範圍。專家判斷需要擴大範圍、或真正問題與原題不同時，說明理由並先詢問使用者。
- 重寫結果用一到數行告知使用者後直接執行；不必等待逐項核准。

## 執行與交付

依重寫後的題目工作。交付時說明：實際查閱的原始素材、使用的方法，以及第 4 點中哪些證據已取得、哪些未驗證。未驗證的項目不宣稱正確。
